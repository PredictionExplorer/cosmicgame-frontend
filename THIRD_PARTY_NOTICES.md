The bundled `assets/fonts/NotoSansSC-700.subset.ttf`,
`assets/fonts/NotoSansTC-700.subset.ttf`, `assets/fonts/NotoSansHK-700.subset.ttf`,
`assets/fonts/NotoSansKR-700.subset.ttf`, and `assets/fonts/NotoSansJP-700.subset.ttf`
files are weight-700 subsets of Noto Sans SC, Noto Sans TC, Noto Sans HK, Noto Sans KR,
and Noto Sans JP (the Simplified, Taiwan, Hong Kong, Korean, and Japanese cuts of Noto
Sans CJK), generated by `npm run og:fonts` from the google/fonts repository. They remain
licensed under the SIL Open Font License 1.1; see
[assets/fonts/OFL-NotoSansCJK.txt](assets/fonts/OFL-NotoSansCJK.txt).

The Japanese and Korean white paper PDFs also embed regular (400) and bold (700)
subsets of Noto Sans JP and Noto Sans KR. `npm run white-paper:pdf` generates these
from the same pinned google/fonts sources, using each complete paper's glyph set.
The embedded fonts retain the SIL Open Font License 1.1 linked above.

The bundled `assets/fonts/Onest-700.subset.ttf` file is a weight-700 subset of
the Onest variable font (its Cyrillic and Vietnamese repertoires, serving the
Ukrainian and Vietnamese locales), generated by the same `npm run og:fonts`
pipeline from the google/fonts repository. It remains licensed under the SIL
Open Font License 1.1; see [assets/fonts/OFL-Onest.txt](assets/fonts/OFL-Onest.txt).

The bundled `public/images/brands/geckoterminal-symbol.svg` file is the
unmodified GeckoTerminal symbol distributed in the official
[CoinGecko and GeckoTerminal brand kit](https://brand.coingecko.com/resources/brand-kit).
It remains subject to its owner's trademark and brand usage terms.
